# SandboxJS
sanxbox, made entirely with js, has a few functions like:
- signin/login
- saving/playing/removing sandbox worlds
- saves cookies, like light or dark mode


## What it uses?
    npm install express ejs mysql2 cookie-parser dotenv bcrypt jsonwebtoken

## .env
    HOST=localhost
    PORT=8000

    DB_HOST=localhost
    DB_USER=root

    DB_PASSWORD=yourpassword
    DB_NAME=sandboxjs
    JWT_SECRET=your_super_secret_key_change_this
